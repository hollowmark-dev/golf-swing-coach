# ゴルフスイング分析PWA (golf-swing-coach)

スマホ(Android Chrome)でゴルフのスイング動画を撮影・保存し、フォーム改善のアドバイスと練習ドリルを提示するPWA。動画・履歴データはすべて端末内にのみ保存され、サーバーには一切送信されません。

現在 **Phase 2** の実装段階です。詳細な設計・フェーズ計画は `.claude/` 配下のプラン、または開発時のやり取りを参照してください。

## できること

- スマホの純正カメラアプリでスロー撮影した動画を選択して取り込む
- 動画は端末内(OPFS)に保存される
- MediaPipe Poseで骨格を抽出し、以下の指標を算出
  - 頭部の上下動、膝の曲げ伸ばし量、手元の軌道の大きさ、テンポ比(バックスイング:ダウンスイング)
- 音声トラックからインパクト(打撃音)の瞬間を推定し、詳細画面から動画をその位置へジャンプできる
- 同一撮影アングルの過去セッションとの比較に基づくルールベースのアドバイスを表示
- 過去のセッション一覧・各指標の推移(トレンドグラフ)を確認できる

APIキーの入力やLLMによる詳細アドバイスは後続フェーズ(Phase 5)で追加予定です。現時点では不要です。

## ローカルでの動作確認

ビルドツールは使用していません(バニラHTML/CSS/JS、CDN経由でライブラリを読み込みます)。

```bash
cd docs
python -m http.server 8000
```

`http://localhost:8000` をブラウザで開いてください。

### 撮影機能の確認について

「動画ファイル」欄はあえて`capture`属性を付けていない、通常の`<input type="file" accept="video/*">`です(付けるとブラウザ内蔵の簡易カメラが強制的に起動し、純正カメラアプリのスローモーションモードに手が届かなくなるため)。実機Androidでの動作確認は、スマホのブラウザから直接アクセスする必要があります。開発中の一時的な確認には、ローカルサーバーを一時的に公開できるトンネルツール(例: `cloudflared tunnel --url http://localhost:8000`)などが使えます。

### 注意: 撮影時はスロー撮影(120fps以上)を推奨

通常の30fps撮影ではダウンスイングからインパクトまで(約0.25秒)を十分な精度で捉えられません。**先に**スマホの純正カメラアプリで「スローモーション」モードに切り替えて撮影し、**その後でこのアプリの「動画ファイル」欄からその動画(またはギャラリー内の動画)を選択**してください。

## データについて

- 動画・骨格データ・アドバイス履歴はすべてブラウザのOPFS/IndexedDBにのみ保存されます
- 端末のストレージを消去したりブラウザデータをクリアすると失われます(バックアップ機能はPhase 4で追加予定)
